DoctorMD — Final Responsive Website Project
============================================

Included:
- index.html — final responsive DoctorMD website
- assets/doctormd-logo.svg — new DoctorMD brand logo
- assets/doctor-profile.png — latest professional doctor portrait with arms-crossed pose
- assets/doctor-brand-banner.png — branded medical banner asset for social/cover use

Features:
- Desktop, tablet and Android/mobile responsive layout
- Clean new navy + teal DoctorMD branding
- Professional hero/profile section using the new doctor portrait
- Mobile hamburger navigation with active section highlighting
- About, services, appointment and contact sections
- WhatsApp appointment form using +92 303 8632790
- Call and WhatsApp buttons
- No external JavaScript libraries

How to publish:
1. Keep the folder structure unchanged.
2. Open index.html locally to test it.
3. Upload the entire DoctorMD_Final_Project folder to your hosting/public_html directory.
